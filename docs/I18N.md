# Translations

The source strings are English and **are the keys**: the code calls
`t("Control Center")`, which returns the translation for the active language and
falls back to English for anything missing.

## Built-in languages

`en` and `it` live in `crates/lard-core/src/i18n.rs` (`const IT`).

## Adding a language without touching the code

Create `~/.config/lard/lang/<code>.toml` (for example `de.toml`):

```toml
"Control Center" = "Kontrollzentrum"
"Notifications"  = "Benachrichtigungen"
"Power off"      = "Ausschalten"
```

Then set the language in `~/.config/lard/config.toml`:

```toml
[ui]
language = "de"   # auto | en | it | <your code>
```

`auto` follows `$LC_ALL`/`$LC_MESSAGES`/`$LANG` and falls back to English. A
partially translated file is fine: unknown keys stay English. The file is loaded
at start-up and on `lard ipc reload`.

Keys are the exact English strings used in the UI; copy them from the source
(`t("…")`) or from the table in `i18n.rs`.
