Wayland · Rust · niri

LARD — install

light as rust dust — native Wayland desktop shell in Rust for niri: island bar, control center, launcher, PAM lockscreen, greetd greeter.

One command

$ curl -fsSL https://lard.francescocallegaro.com/install.sh | bash

Build dependencies (pkg-config, wayland, PAM, fontconfig, vulkan) and the Rust toolchain when missing are installed automatically with the system package manager (pacman, apt, dnf, zypper).

Builds in release and asks for sudo only for system files. No QML, GTK, Qt, Node or Electron: only Rust.

/usr/local/bin/lardthe binary, built on the spot
/etc/lard/config.tomlsystem config + user copy when missing
/etc/pam.d/lard-greeterlockscreen and greeter with native PAM
autostartlard.service enabled, or spawn-at-startup in niri (never both)
Sources and documentation: github.com/francescokalle/lard · installer options: README · uninstall: ./install.sh --uninstall
