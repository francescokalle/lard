LARD — installa

light as rust dust — shell desktop nativa in Rust per niri: barra a isole, control center, launcher, lockscreen PAM, greeter greetd.

Un comando

$ curl -fsSL https://lard.francescocallegaro.com/install.sh | bash

Mancano le dipendenze di build (cargo, pkg-config, …)? Aggiungi -s -- --install-deps: installa tutto con il package manager del sistema.

Compila in release e chiede sudo solo per i file di sistema. Nessun QML, GTK, Qt, Node o Electron: solo Rust.

/usr/local/bin/lardil binario, compilato sul posto
/etc/lard/config.tomlconfig di sistema + copia utente se manca
/etc/pam.d/lard-greeterlockscreen e greeter con PAM nativo
avvio automaticolard.service abilitato, o spawn-at-startup in niri (mai due volte)
Sorgenti e documentazione: github.com/francescokalle/lard · opzioni dell'installer: README · disinstallazione: ./install.sh --uninstall
